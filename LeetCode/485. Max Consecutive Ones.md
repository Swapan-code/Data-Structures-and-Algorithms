[Problem Link](https://leetcode.com/problems/max-consecutive-ones/description/)

**Problem Statement:**

Given a binary array `nums`, return *the maximum number of consecutive* `1`*'s in the array*.

**Example 1:**

```
Input: nums = [1,1,0,1,1,1]
Output: 3
Explanation: The first two digits or the last three digits are consecutive 1s. The maximum number of consecutive 1s is 3.
```

**Example 2:**

```
Input: nums = [1,0,1,1,0,1]
Output: 2
```

**Constraints:**

- `1 <= nums.length <= 105`
- `nums[i]` is either `0` or `1`.

**Approach 1: Linear Scan with Running Counter (Optimal)**

```cpp
class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int n = nums.size();
        int ans = 0, curr = 0;

        for (int i = 0; i < n; i++) {
            if (nums[i]) {
                curr++;
            } else {
                ans = max(ans, curr);
                curr = 0;
            }
        }

        return max(ans, curr);
    }
};
```

Time Complexity: O(N)

Space Complexity: O(1)

**Approach 2: Sliding Window / Two Pointers (Generalizable Variant)**

```cpp
class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int maxCount = 0;
        int left = 0;

        for (int right = 0; right < nums.size(); right++) {
            if (nums[right] == 0) {
                left = right + 1; // Shrink window past the zero
            }
            maxCount = max(maxCount, right - left + 1);
        }

        return maxCount;
    }
};
```

Time Complexity: O(N)

Space Complexity: O(1)
